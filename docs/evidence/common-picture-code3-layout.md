# Общая картинка кода 3: как её отличить от стиля

Классификатор семейств отдавал `Style` всякой записи кода 3 с одним полем
заголовка. На ERP УХ 3.2.12.6 это уводило **673 общие картинки** в
`Styles/*.xml`, и ровно те же 673 `CommonPictures/*.xml` не выдавались.
Множества совпали один в один.

## Различитель

Обе записи имеют код 3 и ровно два поля, второе из которых — блок заголовка.
Расходятся они по **первому члену самого блока**, который объявляет, сколько
членов блок несёт:

| запись | текст | членов блока |
|---|---|---:|
| стиль `Основной` | `{3,{3,{1,0,uuid},"Основной",{2,…},"",0,0,<нуль-uuid>,0}}` | 8 |
| картинка `AppStore` | `{3,{2,{1,0,uuid},"AppStore",{1,…},"",0,0,<нуль-uuid>}}` | 7 |

У семичленного блока нет замыкающего `0`. Больше ничем эти две записи в
дистрибутиве не отличаются — ни кодом, ни числом полей, ни формой маркера.

## Как это стало видно

По одному дистрибутиву не читалось: обе записи выглядят как «код 3, два поля».
Различитель дала **нормализованная пара**, полученная фабрикой семян
(`seed-configurations-method.md`): та же картинка `AppStore`, проведённая через
`config import` + `config save`, возвращается в новой раскладке —

```
дистрибутив ERP УХ:  {1,{3,{2,{1,0,uuid},"AppStore",…}},0}        код 3, блок 2
после импорта:       {1,{4,{3,{1,0,uuid},"AppStore",…,0},0,0},0}  код 4, блок 3
```

— и байтовое сравнение двух редакций одного объекта назвало и код, и версию
блока. Текущая платформа пишет только новую раскладку; код 3 несут лишь
дистрибутивы, собранные до этой смены.

## Область действия

* ERP УХ 3.2.12.6 — 673 таких картинки;
* УТ 11.5.27.75 и БСП демо 3.1.12.297 — ни одной, все их картинки кода 4;
* ERP УХ Web_Service, MDM_Management, WMS5 Модуль Web-обмена, БСП базовая —
  ни одной.

## Измерено

Разность множеств против предыдущего состояния, **сломано 0**:

| | до | после |
|---|---:|---:|
| точных на ERP УХ | 113 063 | **114 448** |
| лишних | 853 | **180** |
| не выдано | 5 624 | **4 280** |
| паритет | 80,52 % | **81,51 %** |

Прибавка 1385 файлов больше 673: картинка — это каталог, `AppStore.xml` плюс
`AppStore/Ext/Picture.xml` и сам файл изображения.

Остаток лишних — 180, крупнейший класс из них 95 файлов вида
`Config_module_text/<uuid>.<n>__part0.bsl`: модульные тексты, ушедшие в
запасной путь вместо своего объекта. Тот же класс виден на БСП WE демо.
