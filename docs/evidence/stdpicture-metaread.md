# Сверка StdPicture по предложению #581

На master `54b796f64da5daed3714acdf7810581fe0e58778` все 221 пары UUID–имя и 17 пар код–имя совпали с приложенным примером. Это даёт независимый способ обнаружить расхождение при обновлении словаря. Для автоматического пополнения остаётся подтвердить происхождение новых пар и их представление при штатной выгрузке.

## Источники

- [metaread, ревизия 41b15a0](https://github.com/gridgt/metaread/tree/41b15a08282eb5bce00e735882f25d35279e2ebe/1C). В V8Types версия конфигурации 0.0.0.3, режим совместимости 8.3.9. `hbkReader` ищет книги синтакс-помощника и загружает описание типов и свойств. Модуль объекта `ВыгрузкаV8Types` обходит справочник типов и пишет линейный диагностический текст. [Описание обработок](https://github.com/gridgt/metaread/tree/41b15a08282eb5bce00e735882f25d35279e2ebe/structure/1C).
- [Генератор из issue](https://github.com/user-attachments/files/33932260/BSL.txt), SHA-256 `18313b6038defafdffdcb1156f2513b70758ea46b74c34bf6b9a21a277d2df09`. В исходнике задан 301 элемент (299 уникальных английских имён). Для каждого он обращается к библиотеке картинок и разбирает сериализованное значение как UUID или отрицательный индекс. Пропуски и исключения допускаются. Сборка платформы, на которой автор получил результат, во вложениях не указана.
- [Результат генератора](https://github.com/user-attachments/files/33932253/default.txt), SHA-256 `5b5e0aa6f69c21e97f25c39af228a1bc8d87255cb7c8bf42a61e7f7464483988`. Все 299 уникальных входных имён представлены в таблицах результата. На закреплённой ревизии в дереве metaread и README явная лицензия проекта не найдена, во вложениях условия использования не указаны. Для сверки используется отдельная реализация и локальная копия входного файла.

Нативная регенерация из вложения здесь не выполнялась.

## Повторение

Сохраните файл результата генератора по ссылке выше и проверьте SHA-256. Из корня указанной ревизии master с добавленным скриптом выполните следующие команды (Python 3.12.3, стандартная библиотека).

```powershell
Get-FileHash ./default.txt
python tools/compare_stdpictures.py ./default.txt
python tools/compare_stdpictures.py ./default.txt --help-book 'C:/Program Files/1cv8/8.3.27.2214/bin/shcntx_root.hbk'
```

Для другой сборки передайте её английскую книгу. JSON содержит полные отсортированные разности пар и оба вида конфликтов. Разности являются результатом измерения. Ошибка чтения или разбора завершает скрипт с ошибкой. По два запуска для каждой из двух книг дали побайтно одинаковый отчёт при одинаковом окружении.

Решение для мейнтейнера — достаточно ли измерения сериализации на закреплённых сборках для включения новых пар в рабочий словарь, или для каждой пары нужен также пример штатного CF/XML. До принятия этого решения кандидаты доступны в отчёте для повторной проверки.
