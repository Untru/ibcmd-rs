# Сверка StdPicture по предложению #581

На master `54b796f64da5daed3714acdf7810581fe0e58778` все 221 пары UUID–имя и 17 пар код–имя совпали с приложенным примером. Это даёт независимый способ обнаружить расхождение при обновлении словаря. Для автоматического пополнения остаётся подтвердить происхождение новых пар и их представление при штатной выгрузке.

## Источники

- [metaread, ревизия 41b15a0](https://github.com/gridgt/metaread/tree/41b15a08282eb5bce00e735882f25d35279e2ebe/1C). Модуль объекта `ВыгрузкаV8Types` обходит справочник типов и пишет линейный диагностический текст. [Описание обработок](https://github.com/gridgt/metaread/tree/41b15a08282eb5bce00e735882f25d35279e2ebe/structure/1C).
- [Генератор из issue](https://github.com/user-attachments/files/33932260/BSL.txt), SHA-256 `18313b6038defafdffdcb1156f2513b70758ea46b74c34bf6b9a21a277d2df09`. В исходнике задан 301 элемент (299 уникальных английских имён). Для каждого он обращается к библиотеке картинок и разбирает сериализованное значение как UUID или отрицательный индекс. Пропуски и исключения допускаются. Сборка платформы, на которой автор получил результат, во вложениях не указана.
- [Результат генератора](https://github.com/user-attachments/files/33932253/default.txt), SHA-256 `5b5e0aa6f69c21e97f25c39af228a1bc8d87255cb7c8bf42a61e7f7464483988`. Все 299 уникальных входных имён представлены в таблицах результата. На закреплённой ревизии в дереве metaread и README явная лицензия проекта не найдена, во вложениях условия использования не указаны. Для сверки используется отдельная реализация и локальная копия входного файла.

Повторный замер выполнен отдельным модулем управляемого приложения.

## Повторение

Сохраните файл результата генератора по ссылке выше и проверьте SHA-256. Из корня указанной ревизии master с добавленным скриптом выполните следующие команды (Python 3.12.3, стандартная библиотека).

```powershell
Get-FileHash ./default.txt
python tools/compare_stdpictures.py ./default.txt
python tools/compare_stdpictures.py ./default.txt --help-book 'C:/Program Files/1cv8/8.3.27.2214/bin/shcntx_root.hbk'
```

Для другой сборки передайте её английскую книгу. JSON содержит полные отсортированные разности пар и оба вида конфликтов. Разности являются результатом измерения. Ошибка чтения или разбора завершает скрипт с ошибкой. По два запуска для каждой из двух книг дали побайтно одинаковый отчёт при одинаковом окружении.

Решение для мейнтейнера — достаточно ли измерения сериализации на закреплённых сборках для включения новых пар в рабочий словарь, или для каждой пары нужен также пример штатного CF/XML. До принятия этого решения результат генерации предназначен для сверки.

## Замер в платформе и генерация

В двух временных файловых базах выполнили сериализацию `БиблиотекаКартинок` по объединённому списку из 301 имени. 8.3.27.2214 воспроизвела все 279 UUID и 20 кодов примера. 8.5.1.1529 воспроизвела те же пары и добавила `SortedAsc` (`e4c49dfb-ef8e-4f4a-9d01-9536ba61f944`) и `SortedDesc` (`34c981c1-f0bd-43e0-a0cf-c2a9cd648b91`). В 8.3.27.2214 обращения по этим двум именам завершились ошибкой. Сгенерированные модули на обеих версиях совпали с master по 221 UUID и 17 кодам.

1. Создайте пустую файловую базу целевой сборки. Выгрузите конфигурацию в каталог через `DESIGNER /DumpConfigToFiles`.
2. Сгенерируйте модуль в `Ext/ManagedApplicationModule.bsl` внутри выгрузки. Передайте английскую книгу целевой сборки. Ключ `--sample` добавляет имена из вложения для проверки недокументированных картинок. Для точного повторения общего списка из 301 имени на обеих сборках используйте книгу 8.5.1.1529 и вложение.

   ```powershell
   $module = python tools/generate_stdpictures.py prepare $helpBook $runtimeTsv --sample ./default.txt
   if ($LASTEXITCODE -ne 0) { throw 'Picture probe preparation failed' }
   New-Item -ItemType Directory -Force "$xml/Ext" | Out-Null
   $module | Set-Content -Encoding utf8BOM "$xml/Ext/ManagedApplicationModule.bsl"
   ```

3. Загрузите конфигурацию в эту временную базу через `DESIGNER /LoadConfigFromFiles /UpdateDBCfg` и дождитесь его завершения. Запустите `ENTERPRISE /L en`. При запуске приложение запишет TSV на заданный путь и завершится.
4. Сгенерируйте и сравните модуль. При повторении общего списка на 8.3.27.2214 добавьте `--allow-missing SortedAsc --allow-missing SortedDesc` к команде `generate`. Параметр требует точного совпадения фактического списка ошибок с ожидаемым.

   ```powershell
   python tools/generate_stdpictures.py generate $runtimeTsv > ./generated.rs
   python tools/compare_stdpictures.py ./generated.rs
   ```

Замер относится к представлению `БиблиотекаКартинок` во внутренней сериализации. Допуск этих пар в рабочий словарь по штатному CF/XML остаётся отдельной приёмкой.
