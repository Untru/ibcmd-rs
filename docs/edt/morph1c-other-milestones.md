## Adoption order

1. Finish independently verified EDT source conversion in 0.7. Its private vendor
   types must not become a public core model.
2. Evaluate the CF/body closure for 0.6 and the version/coverage tables for 0.8.
   List the exact files and dependencies before copying; retain attribution and
   audit any embedded platform-derived data separately.
3. Use specific payload facts for 0.5 when a native differential fixture verifies
   them. Never infer generation activation behavior from a converter.
4. Treat PostgreSQL, 1CD and editor work as separate architecture tasks. Codec
   reuse can reduce payload work but does not supply their transport/protocol.

Nothing in this matrix completes an issue in another milestone or expands the
0.7 implementation scope. Links identify the assessed historical snapshot;
future upstream improvements need a fresh assessment and independent acceptance.
