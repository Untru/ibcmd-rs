# PostgreSQL в режиме подмены, #371

Стенд 24 ноября 2026 г. — Windows, PostgreSQL 17.2-4.1C, штатные
8.3.27.2342 и 8.5.1.1529. Обе сборки запускались напрямую из своих
каталогов установки. Для каждой использовались отдельная база, каталог
`--data` и штатная выгрузка.

## Проверка командной строки

На обеих сборках `infobase config export` и `import` с
`--dbms=PostgreSQL --db-server=127.0.0.1 --db-user=postgres <каталог>`
возвращают 2 с сообщением «Не указано значение параметра: db-name».
Раньше подмена начинала операцию и возвращала −1. Если имя задано,
а сервер отсутствует, штатная программа требует `db-server`.
Проверка подмены учитывает настройки, из которых можно получить
параметры подключения.

## Привязка платформы

Для проверки использованы конфигурации репозитория
`tests/fixtures/file-infobase/empty-xml-8.3.27` и
`tests/fixtures/file-infobase/tiny-source`. В отдельной отрицательной
проверке штатная 8.3.27.2342 отказалась импортировать XML 2.21 и
вернула −1. Реестр подмены на исходном master отклонял точную версию
8.3.27.2342 ещё при разборе `--platform` с кодом 2.
