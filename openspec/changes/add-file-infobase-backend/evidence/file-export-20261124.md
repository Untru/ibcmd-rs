## БСП 3.1.11.309

Обе штатные платформы создали отдельные файловые базы из одного поставочного
`SSL/3_1_11_309/1Cv8.cf` (67 167 823 байта, SHA-256
`4ded13b6b6b5c74f11c544e6be442cbea6f49eb8dede3424841b4bd6af4b4448`).
Для обеих штатных выгрузок в `Configuration.xml` прочитаны
`БиблиотекаСтандартныхПодсистем`, версия `3.1.11.309`,
`ScriptVariant=Russian` и `DefaultLanguage=Language.Русский`.
Язык интерфейса и региональный формат Windows — `ru-RU`.
Процессы наследовали `LANG=ru_RU.UTF-8` и `LC_ALL=ru_RU.UTF-8`.

Для каждой строки использовались своя пара каталогов базы и данных сервера
и штатный `ibcmd.exe` указанной сборки. Все четыре штатные команды в обеих
строках завершились с кодом 0.

```powershell
& $native infobase create "--db-path=$db" "--data=$data" --create-database --locale=ru_RU
& $native infobase config load "--db-path=$db" "--data=$data" $cf
& $native infobase config apply "--db-path=$db" "--data=$data" --force
& $native infobase config export "--db-path=$db" "--data=$data" $reference
& $candidate infobase config export "--db-path=$db" "--platform=$profile" $output
```

`--platform=8.3.27.2342` завершился за 4,67 с с кодом 2 при проверке

## Контроль известных расхождений ERP 2.6.1.64

Для повторной проверки использованы две сохранённые одноразовые базы и
штатные деревья из [октябрьского прогона](https://github.com/Untru/ibcmd-rs/issues/373#issuecomment-6348772107).
Идентификатор конфигурации в обоих эталонах — `УправлениеПредприятием`,
версия `2.6.1.64`, основной язык `Language.Русский`.
Эталон 8.3 получен Конфигуратором **8.3.27.2214**, эталон 8.5 — штатным
ibcmd **8.5.1.1529**.

* `DataProcessors/ИнтерфейсДокументовЭДО/Forms/ТекущиеДелаПоЭДО/Ext/Form.xml`.
  В обеих выгрузках master перенёс два поля в начало соответствующих списков
  `UseAlways` и записал их как `~ВходящиеЭД.ПометкаУдаления` и
  `~ИсходящиеЭД.ПометкаУдаления`. Штатные выгрузки записали имена без
  тильды. Это все отличия в этом файле при профилях `8.3.27` и
  `8.5.1.1529`. Укороченный профиль `8.5.1` дополнительно опускает
  `ButtonImportance=Main`. Различие зависит от выбора сборки,
  см. [PR #479](https://github.com/Untru/ibcmd-rs/pull/479).
* `DataProcessors/РаботаСРезультатамиОбмена/Forms/ОбъектыКПоискуИУстановкеСоответствий/Ext/Form.xml`.
  На `8.5.1.1529` выборочная выгрузка этой формы завершилась с кодом 0.
  SHA-256 штатного и полученного файлов —
  `42e47f73a57ab8c229a850d5d90ac00fabea696c6fc00c785a5dcb146a340765`.
  Прежний отказ на `TitleBackColor` исправлен в
  [PR #487](https://github.com/Untru/ibcmd-rs/pull/487).
