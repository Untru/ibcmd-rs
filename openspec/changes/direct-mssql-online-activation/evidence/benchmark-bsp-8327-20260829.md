# BSP source export benchmark on platform 8.3.27

## Environment

- Date: 2026-08-29, Europe/Moscow.
- Database: MSSQL `BSP_Service`.
- Infobase user: `Администратор`, empty password.
- Native oracle: `C:\Program Files\1cv8\8.3.27.2214\bin\ibcmd.exe`.
- Native version output: `8.3.27.2214`.
- Registered cluster: `24c580ef-d5de-4b78-b204-b94b64eb2fae`.
- Cluster server port: `2541`; RAS port: `2545`.
- `ibcmd-rs`: release build at commit `4a4d2f49` plus evidence-only
  working-tree changes.
- Retained artifacts: `E:\ibcmd_lab\benchmark_8327_bsp_20260829_1310`.

The measured `ibcmd-rs` command exported XML/BSL sources and suppressed raw
storage rows and diagnostic inflated copies:

```text
ibcmd-rs mssql-dump-config --server localhost --database BSP_Service \
  --output-dir <output> --extract-module-text --extract-metadata-xml \
  --source-version 2.20 --no-binary-rows
```

The native oracle command was:

```text
ibcmd config --dbms=MSSQLServer --db-server=localhost \
  --db-name=BSP_Service --user=Администратор export <output>
```

Build time was excluded. No test 1C client was active during measurements.

## Results

| Tool | Run 1 | Run 2 | Mean | Source files |
|---|---:|---:|---:|---:|
| native `ibcmd` 8.3.27.2214 | 22.741 s | 21.515 s | 22.128 s | 12,198 |
| `ibcmd-rs` release | 18.317 s | 19.123 s | 18.720 s | 12,198 + `manifest.json` |

`ibcmd-rs` was **15.40% faster**, or **1.182x** by mean wall-clock time.

The generated `manifest.json` is 6,862,611 bytes and was not counted as a 1C
source file. A byte-level `source-diff` between native run 2 and our run 2
reported:

```text
left_only  = 0
right_only = 1  (manifest.json)
different  = 0
unchanged  = 12198
```

Therefore this timing comparison used byte-identical 1C source output; the
only extra file was our diagnostic manifest.

The second `ibcmd-rs` report attributed its critical path as follows:

```text
fetch_headers_ms    = 96
prepare_indexes_ms  = 3360
fetch_rows_ms       = 3723
process_rows_wall_ms= 11267
```
