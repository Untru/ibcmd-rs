# Дизайн: selected CF extract

Команда индексирует CF bounded streaming reader-ом, требует единственное точное
имя элемента и читает только его payload. Представление payload задаётся
`--compression`; packed и decoded hashes вычисляются до публикации.

Каталог назначения обязан отсутствовать, а его родитель — существовать. После
полной проверки команда создаёт каталог и пишет `packed.bin` и `unpacked.bin`.
При ошибке второй записи созданные командой файлы откатываются. Существующие
файлы и каталоги никогда не удаляются и не заменяются.
