# Предложение: точечное извлечение CF evidence

## Зачем

`cf inspect --element` доказывает хэши выбранной записи, но не публикует её
байты. Для immutable native corpus приходилось бы хранить или декодировать весь
CF, что замедляет исследовательский цикл и увеличивает риск ручной ошибки.

## Что меняется

- Добавляется `cf extract` для одного точного top-level element.
- Compression остаётся явным CLI-контрактом и никогда не угадывается.
- Packed и unpacked bytes публикуются только в новый каталог.

## Результат

Raw/XCF evidence для одного объекта извлекается потоково за секунды без полной
выгрузки CF и без перезаписи существующих артефактов.
