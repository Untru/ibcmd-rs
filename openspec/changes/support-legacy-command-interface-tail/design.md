# Дизайн

Поиск владельца больше не использует `text.contains(uuid)`: произвольная
подстрока не доказывает ownership. Для каждой metadata row строится набор
структурно разобранных command headers, после чего проверяется полное и
однозначное покрытие unresolved set.

Legacy visibility-only tail является самостоятельным закрытым wire profile.
Он распознаётся сравнением всего остатка записи с тремя пустыми секциями, а не
как префикс расширенного формата.
