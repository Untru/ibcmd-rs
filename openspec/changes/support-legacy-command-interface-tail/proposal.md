# Предложение: строгий legacy tail командного интерфейса

## Зачем

Selected export должен находить владельца unresolved команды без широкого
сканирования UUID-подстрок. Сохранённый legacy command-interface profile после
visibility содержит ровно три пустых tail-секции, тогда как общий decoder
ожидал расширенный пятисекционный хвост и отклонял валидный источник.

## Что меняется

- Владелец команды подтверждается только структурным command header.
- Для каждого unresolved UUID требуется ровно один владелец; дубликат
  отклоняется.
- Command-interface decoder принимает только exact legacy tail `0,0,0`.
- Любая иная arity или non-zero секция идёт по общему строгому пути и
  отклоняется, если профиль неполон.
