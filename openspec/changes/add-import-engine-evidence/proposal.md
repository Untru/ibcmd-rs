# Engine-owned diagnostic import evidence

## Why

Refs #382. SQL import diagnostics retain export reports but cannot recover owner authority from reduced output indexes. The engine must expose bounded observations through its existing decoders without promoting normalized headers or caller labels into authorization.

## What changes

Add an isolated synchronous observer under mssql_dump. Borrow immutable packed candidates for one view and return owned occurrence-preserving diagnostics and exact computed digests. Observe existing four-family graph collections with their schema provenance. Keep full parent, source asset routes, versions, storage projection and overall completeness explicitly unsupported. No production consumer, SQL route, publication or existing FileDb behavior changes.
