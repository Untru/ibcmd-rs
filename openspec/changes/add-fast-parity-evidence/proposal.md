# Предложение: добавить быстрый platform-authenticated parity corpus

## Зачем

Полный цикл загрузки и выгрузки конфигурации слишком дорог для каждой
итерации raw-to-XML декодера. Синтетические raw fixtures быстры, но не доказывают
соответствие реальной платформе.

## Что меняется

- Добавляется минимальный diagnostic-only CF corpus, подтверждённый двумя
  нативными round-trip на 1С 8.3.27.2214 и XML 2.20.
- Каждая fixture получает machine-readable provenance и строгие SHA-256 guards.
- Первый вертикальный срез Task проверяет полный byte parity нативного XML.
- Unica используется для построения seed, но не считается источником истины.

## Результат

Основной цикл проверки Task работает офлайн за секунды, а изменения правил
остаются привязаны к точному нативному доказательству.
