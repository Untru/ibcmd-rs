# Design

The final comparison continues indexing all leaf values and attributes. Paired and self-closing empty leaves share a representation; absence remains distinct. Character references contribute their decoded content, and unknown references fail. Metadata Type sorting requires resolved metadata/core namespaces and unique, plain, nonempty members. Qualifiers and ambiguous members remain ordered. Rights normalization requires the roles namespace, unqualified content with no nested namespace rebinding and unique object names. The bound root XSI type Rights is admitted without dropping its value or namespace declaration; reserved xml/xmlns aliases are excluded. Colliding root keys in the legacy diagnostic index refuse before byte/hash identity or leaf fallback. Every indexed object value is rekeyed by its full name, including rights and RLS. No revocation is ignored.

DCS comparison delegates only for a strict DataCompositionSchema root in its schema namespace. The existing conservative unused-prefix proof and content checks remain authoritative.

Form repairs use measured native coordinates and typed schema owners: MediumGreen 88, search-addition width, CatalogRef standard member Parent -4 and scoped UseAlways column resolution. The physical reader delegates instead of acquiring new layout policy. Document tabular-section fill export omits only the exact legacy empty-string/false pair. Nil and real false values remain distinct.

The XML 2.20 Form route compares qualified trees and is authoritative: a refusal cannot fall back to the older local-name index. It permits only native-witnessed defaults at typed owner paths: CheckBoxField Auto, UsualGroup ShowTitle true, nil RowFilter bound directly to a singleton ValueTable attribute, the three root defaults for a unique main DocumentObject attribute, and UsualButton for a direct root ordinary Button. Semantic collections retain complete heterogeneous order. Unknown properties, namespaces, significant text and mixed content remain strict. Namespace removal protects every prefix used on either side; uncertain proofs preserve declarations. Original namespace validity is checked before any removal.

Modern UsualGroup base patches route ShowTitle to its own typed option independently of EnableContentChange. Requested edits on unadmitted modern layouts refuse instead of borrowing the historical field. Designer XML button omission is handled at the source boundary without changing internal command-bar formatter defaults. Document patches transfer only the two fill slots of UUID-matched tabular-section attributes and preserve every other descriptor coordinate.

External-source Table edits clone a validated 52-slot descriptor and change only its schema-owned TableDataType coordinate. Complete candidate XML must equal the source under the namespace-exact structural-indentation comparator before it can be returned. Other edits and profiles fail closed.

Broad XML canonicalization, global element sorting, generic property omission, relaxed namespace comparison, inferred native slots and modifications to the physical-adapter baseline are excluded. Local native evidence and private application material remain outside the repository. A complete guarded import and database apply are separate acceptance measurements; unit tests alone do not complete either.
