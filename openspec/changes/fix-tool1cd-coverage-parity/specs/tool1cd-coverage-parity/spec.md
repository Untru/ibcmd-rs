## ADDED Requirements

### Requirement: Tool1cd-backed converter repairs

The converter SHALL preserve supported metadata scalar values and objects across CF/SQL/XML routes using measured schema rules, without cases for object names.

#### Scenario: A platform-proven Coverage property differs

- **GIVEN** a public native-built variant reproducing an incorrect value or omitted object
- **WHEN** its storage rule is confirmed independently against pinned tool1cd and native bytes
- **THEN** the repaired converter produces the native value and retains every previously supported variant
- **AND** unrecognized members or codes remain explicit refusals

### Requirement: Account for every observed class

The evidence SHALL identify the tool1cd applicability and measured disposition of all 104 audit signatures and export clusters.

#### Scenario: A runtime property is named without storage grammar

- **GIVEN** an audit signature with a Coverage witness and a similarly named tool1cd runtime property
- **WHEN** no applicable storage coordinate or binary profile is established
- **THEN** the class remains explicitly unresolved
- **AND** no guessed implementation or successful-coverage claim is published
