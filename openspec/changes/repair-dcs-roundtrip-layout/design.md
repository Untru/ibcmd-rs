# Design

Use the existing lossless XML reader and the structural-comparison precedent in `ibcmd-xml`. Compare raw start/end markup and every non-structural node exactly. A container is structural only when both documents contain child elements and contain no other character content except literal XML whitespace. Honor inherited `xml:space`, including a nested `default` reset. Comments and processing instructions remain exact.

Ignore only literal whitespace text nodes in such containers. A whitespace character reference is not literal indentation. Leaf text, whitespace-only leaf values, query line endings, CDATA and mixed character content remain exact. Invalid XML cannot compare equal. Add a bounded comparison entry point beside the existing lossless XML comparison API so private raw accessors stay private. Use it only in the DCS round-trip gate; do not alter the existing line-ending comparator, source files, storage writer, exporter, SQL routing or database apply.

A global CRLF/CR replacement was rejected because it can hide changes in literal query and scalar content. An allowlist of individual container names would miss other supported layouts such as selection items and duplicate schema policy. Generic XML canonicalization would relax namespace, attribute and scalar spelling beyond the reported defect.

Tests use existing clean-room native fixtures and literal negative examples. Private application inputs and diagnostic exports remain outside the repository. A successful codec test does not establish a successful full configuration import or database apply.

The DCS-only entry point may additionally omit proven unused prefixed namespace declarations before the structural comparison. The two existing general-purpose comparison APIs remain namespace-exact. Determine usage conservatively across both entire documents: element/attribute names, decoded attribute values, joined decoded text and opaque content must retain possible references, including encoded or split QName prefixes. A globally used prefix retains every declaration even across scope rebinding. Retain default declarations and any declaration whose non-usage cannot be established. Remove only quote-aware raw attribute spans checked against parsed ordered names and values; preserve every other byte. Declaration-like text inside ordinary attribute values is never a removal span.
