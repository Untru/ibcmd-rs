# Предложение: ibcmd-rs как сервер для редактора кода

Задачи: Untru/ibcmd-rs#376 (архитектура и протокол), Untru/ibcmd-rs#377
(`ibcmd-rs serve --stdio`).

## Зачем

С конфигурацией хочется работать из редактора кода (VS Code, Cursor,
VSCodium): дерево объектов базы, выгрузка и загрузка выбранных объектов
правой кнопкой, сравнение с базой. Каждое такое действие должно занимать
секунды, а запуск `ibcmd-rs` на каждое действие заново читает базу и строит
индексы выгрузки.

## Что меняется

- `ibcmd-rs serve --stdio` — долгоживущий процесс, один на окно редактора:
  JSON-RPC 2.0 поверх stdin/stdout с кадрами `Content-Length`, как у LSP;
  сеть и порты не нужны.
- Процесс держит соединения с базой (пул встроенного клиента SQL Server),
  кэш дерева и выгруженных объектов, сбрасываемый при смене строки
  `versions`; долгие операции отменяются (`$/cancelRequest`), о ходе работы
  сервер шлёт уведомления `progress` и `log`.
- Сервер вызывает те же библиотечные функции, что и командная строка; всё,
  что умеет редактор, доступно и из CLI:
  - `mssql-dump-config --object <полное имя>` — выгрузка выбранных объектов
    (строки объекта и принадлежащих ему форм, макетов, перерасчётов, вложенных
    подсистем);
  - `ibcmd-rs objects tree|status|read|export` — дерево, сверка с папкой
    исходников, файл объекта без записи на диск, выгрузка объектов в папку;
  - загрузка — `mssql-stage-source-objects --path-prefix`, неприменённые
    изменения — `mssql-apply-check`.
- В `[[database]]` файла `ibcmd-rs.toml` появляется необязательный ключ
  `rows-dir`: таблица Config такой базы читается из папки сохранённых строк
  (офлайн-источник `mssql-dump-config --rows-dir`), без SQL Server.
- Пароль хранится в SecretStorage редактора и передаётся серверу в памяти
  (`infobases/connect`): не в аргументах, не в файлах, не в логах.

Расширение — тонкая оболочка на TypeScript в `editors/vscode/` (не в этой
задаче). Протокол и исполняемый файл выпускаются вместе, `initialize` сверяет
версии.

## Результат

Протокол (методы, уведомления, ошибки, совместимость версий) — `design.md`.
Прототип `serve --stdio` с интеграционными тестами через каналы на офлайн-
корпусе: файлы на выходе те же, что у командной строки (`cf export`,
`mssql-dump-config --rows-dir --object`).
