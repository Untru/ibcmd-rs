## Задача 4: проверка

**Статус:** офлайн и SQL RPC проверены; замер ERP УХ открыт.

- [x] `tests/editor_server.rs`: сервер через каналы на папках строк из
  `.cf`-фикстур; выгрузка каждого объекта совпадает с `cf export` и
  `mssql-dump-config --rows-dir --object`, `source/read` — с файлами
  выгрузки, сверка и восстановление папки, отмена запроса в очереди,
  ошибки протокола, коды завершения; пароль не попадает ни в ответ, ни в
  уведомления; после смены строки `versions` объект перечитывается (тело
  формы переписано в папке строк — до смены версии ответ из кэша, после —
  новый текст модуля и новый `version`).
- [x] Дерево, выгрузка, сверка, подтверждённый SQL-импорт с `verify` и оба режима `config/pending` через stdio. [Корпус и результаты](sql-rpc-evidence.md).
- [ ] Время открытия модуля и успешной выгрузки документа на точной ERP УХ.

Прямой SQL-вызов `objects/import` с `objects` и `confirm: true`
заменяет ConfigSave. Расширение для выбранных файлов использует
`objects/import/prepare` и одноразовый план. Для SQL этот путь зависит от
#640. Проверка прямого вызова сама по себе не подтверждает сохранение чужой
стадии или применение конфигурации.
