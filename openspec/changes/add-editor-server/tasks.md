## Задача 4: проверка

**Статус:** `[x]` офлайн, `[ ]` SQL Server

- [x] `tests/editor_server.rs`: сервер через каналы на папках строк из
  `.cf`-фикстур; выгрузка каждого объекта совпадает с `cf export` и
  `mssql-dump-config --rows-dir --object`, `source/read` — с файлами
  выгрузки, сверка и восстановление папки, отмена запроса в очереди,
  ошибки протокола, коды завершения; пароль не попадает ни в ответ, ни в
  уведомления; после смены строки `versions` объект перечитывается (тело
  формы переписано в папке строк — до смены версии ответ из кэша, после —
  новый текст модуля и новый `version`).
- [ ] Прогон на лабораторной базе SQL Server: дерево, выгрузка, сверка,
  `objects/import` с `verify`, `config/pending`; замер времени запросов на
  ERP УХ.
