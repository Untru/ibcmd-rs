# Design

A paired source/storage observation identifies the same three panel identities in an unchanged tracked interface and its existing native configuration row: two absent heights have terminal coordinates `2,0`, and one explicit height `1` has `2,1`. Existing public native fixtures independently cover the absent/default coordinate. Application artifacts, identifiers and paths stay outside the repository; tests use synthetic identities and minimized protocol shapes.

Carry this coordinate through the XML parser, compiler model, native serializer, native reader and XML formatter. The typed codec beside the serializer owns exact native admission, shared protocol constants and full panel XML projection; the physical adapter delegates and retains both UUID checks. Preserve the order after `uuid` and every existing group/area/panel-definition behavior. Add a typed height value for the witnessed non-default case rather than an arbitrary native token escape.

The supported cohort deliberately includes only absence and explicit height `1`. Explicit XML `0`, heights `2` or greater, negative/noninteger values, duplicate/extra XML properties, and unknown/incomplete/extra native tail fields remain refused until native evidence establishes their meaning. No application-name or panel-UUID exceptions are introduced. No source XML files, database apply paths or SQL compatibility routing change.

Tests pin exact native bytes and exact exported XML, retain the existing native default-panel fixture, and cover refusals. Acceptance requires an offline round trip of the original interface plus a separately timed guarded full import; any later blocker keeps full-load acceptance open.
